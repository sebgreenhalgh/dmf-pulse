## Interfaces and custody

`dmf forecasts inventory` reads only shipped hash-bound metadata, without a
recursive scan, provider, credential, DB or model operation. `dmf forecasts verify
--artifact <path>` hashes one explicit local regular file up to64MiB. Unknown bytes
remain UNVERIFIED_CUSTODY regardless of asserted JSON fields; pickle and JSON
bodies are never deserialized by verification. Directory, link/reparse, FIFO,
UNC, secret-like and oversized inputs fail closed with safe error codes. File
identity and stability are checked across hashing. Neither command writes an
artifact or confers source rights or scoring authority.

The paired Model Performance API adds the recovered catalogue before any optional
synthetic diagnostics. P01 is explicitly MATCH evidence; real player cohort
eligibility remains separate. Temporal classification, retention qualification,
label availability and evaluation readiness are independent fields. The
catalogue is immutable research-review metadata, not operational enrollment or
a parallel control ledger. The dashboard performs no vault query and does not
enable Refresh, evaluation, source access or promotion from these metadata.
