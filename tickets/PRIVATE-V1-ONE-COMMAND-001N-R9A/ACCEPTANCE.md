# R9A acceptance

R9A provides strict, immutable, transient official-FPL Gameweek player-history evidence.
It is `EVIDENCE_ONLY_NOT_MODEL_INPUT`: it must not alter Stage 7, Stage 9, R7/R8B,
the ordinary recommendation, provider request classes, rights, retention or activation.
Raw event-live bodies are never persisted; only safe in-memory digests are retained.

Required checks include strict retained-field parsing, missingness, current identity binding,
window selection, reconciliation applicability/failure, deterministic sealing, no network or
filesystem work in assembly, frozen recommendation equality, installed wheel, manifests,
repository validation and independent review.
