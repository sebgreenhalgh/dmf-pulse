## OBJECTIVE

Transform Seb's Desk into a persistent, browser-based FPL analysis workspace with a permanent local, queryable database.

The user must be able to:

1. Run the installed launcher and immediately see the latest saved recommendations.
2. Browse all previously retained forecast runs without acquiring data or consuming credits.
3. Click a browser button to deliberately refresh data and recommendations.
4. Enter a newly issued FPL JWT in a secure local browser prompt triggered by that button.
5. See progress and the new recommendations after successful execution.
6. Have all permitted derived analytics saved automatically to a durable local database.
7. Explore that database using local AI tools, Codex, Python or SQL without re-executing the pipeline.

**Content creation is explicitly outside this implementation.** Do not build Instagram, TikTok, video generation, posting automation or public sharing.

The database must nevertheless preserve enough validated decision evidence for separate, future content research.
