# GW1-PLY-002 source governance

The only calibration source is the Pappalardo / Wyscout Soccer Match Event
Dataset Figshare collection, `10.6084/m9.figshare.c.4415000`, collection
version 5. The retained candidate identifies three exact public items and
members: Players `7765196.v3` / `players.json`, Events `7770599.v1` /
`events_England.json`, and Matches `7770422.v1` / `matches_England.json`.

Each required item was independently checked as `CC BY 4.0` before download.
Attribution is retained in the immutable candidate artifact: Pappalardo, Luca;
Massucco, Emanuele (2019), Soccer match event dataset, and Pappalardo et al.
(2019), *A public data set of spatio-temporal match events in soccer
competitions*, Scientific Data 6:236.

Only exact download/member hashes and aggregate estimates are committed. Raw
source archives and JSON remain in a local temporary cache and are not vendor
data, test fixtures, logs, or current-player mappings. The CC-BY release does
not change the separate rights status for official current FPL history.
