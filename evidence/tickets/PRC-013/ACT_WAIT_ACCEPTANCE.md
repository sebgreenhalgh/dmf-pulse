# ACT/WAIT acceptance

`ACT_NOW`, `WAIT_FOR_INFORMATION` and `DO_NOT_TRANSFER` are mandatory alternatives. Ranking uses
complete declared utility components: football value, affordability, price scenarios, outgoing
selling risk, free-transfer value, recourse, information, hits, injury/rotation, reversal, lost
purchase position and execution risk. Price probability is context/component only and is never a
direct action threshold. Live uncalibrated mode returns non-actionable manual review.

Adversarial coverage includes price-only hit, false alarm, press-conference information value and
otherwise-expiring free transfer cases.
